# K-I-N｜部落之间的生活与失去领导权 v0.1

**日期：2026-10-05｜分类：预期感受｜状态：体验方向已确认，功能尚未验收**

本页描述玩家应当经历什么。具体规则见[贸易、战争与派系设计](../02_设计文档/部落贸易战争与派系涌现_v0.1.md)，实现边界见[数据契约与验收](../03_技术方案/多部落社会模拟_数据契约与验收_v0.1.md)。本页场景是可能发生的例子，不是必须播放的剧情。

## 1. 最重要的体验承诺

> 我可以参与建立一个部落，也可以失去它的领导权。别人会记住我做过的事，但不必永远听我的。我仍然可以留在这个世界里，继续工作、交易、帮助别人、离开或重新争取支持。

玩家已明确认可“自己建立的营地因意见分歧支持另一位首领，而自己继续生活”的体验方向。设计必须允许这种结果，但绝不为制造戏剧强迫它发生。

顺利合作、保持领导、和平处理分歧，同样是有效历史。没有政变不等于系统失败。

## 2. 第一眼看到的世界

玩家进入一个陌生河谷，起初只知道附近有自己的营地。沿路发现经常被踩踏的小径、带着货物的陌生人、与自己营地不同的储物标记。

有人提到：“山边的人隔几天会来换食物。”玩家由此认识邻营，而不是先打开一张全知地图看见所有阵营关系。

两个营地可以在玩家到来之前就有共同经历。这些开局经历若作为设定加入，必须标记为开局背景；只有真正经过模拟执行的事件才叫模拟历史。不能伪装成系统已经运行过几十年。

玩家不干预时，已具备条件的运输、交换、协商和救援仍应继续。世界也可以一段时间平静地生活，不必不停制造大事。

## 3. 从一份食物开始的贸易

河边营地更方便捕鱼，山边营地更方便取得药材。双方都能维持基本生存，但交换可以节省劳动或改善照料条件。

玩家看见的不是两座仓库之间数字瞬间跳动，而是具体的人整理货物、出发、等待、交付、返回。负责运输的人暂时不能留在营地捕鱼，也可能想多分一点收益。

一次交易让伤员家庭获得药材，却让另一个家庭担心自己的食物被运走。同一笔成功交易，能够产生不同感受；不自动给所有成员增加同样的好感。

玩家可以做运输者、护送者、交易伙伴、担保人，也可以只是路上提供帮助的人。并非只有首领才能接触这个玩法。

## 4. 一次没有按时返回的运输

可能的经过：运输者遭到野兽袭击，货物仍在途中。收货营地只知道“约定时间已过”，不知道真正原因。

一个人要求搜救；一个人怀疑对方反悔；运输者的熟人不愿立刻指责；担心口粮的人要求停止下一次发货。

玩家可以寻找线索、救回运输者、带回部分货物、提供消息或不参与。结果会改变人物的伤势、交易状态、信任，以及谁的意见更有分量。

被救的人不必立即加入玩家。他可能选择回家、继续运输，也可能因为伤势不再走那条路。玩家的帮助留下关系，却不自动制造服从。

## 5. 贸易关系怎样成为冲突

在另一条历史里，货物可能确实被某个成员私自拿走。但“一个人拿走东西”也不自动等于“整个部落决定掠夺”。

玩家可以看见指控、要求返还、内部追责、拒绝赔偿、组织护送或有限报复。这些行动有明确参与者，而不是所有带同样标记的人瞬间成为敌人。

冲突也有降温路径。归还、补偿、重新担保、共同救援，都可能让双方继续合作。关系修复不等于删除旧事；被伤害的人可能接受补偿，却仍对下一次交付更加谨慎。

## 6. 派系从熟人关系中变得可见

一开始，营地里的几个人经常一起运输，另几个人更关心留给本营地的食物。只有意见相近还不算派系。

后来，一群人反复为彼此担保、共同安排劳动、支持同一个分配方案，开始把资源交给自己认可的协调者。玩家通过“谁和谁一起做事、谁在替谁说话”发现一个群体正在形成。

派系可以支持现任首领，也可以反对某一项决定而继续合作。它不必以分裂或暴力作为终点。

家族、营地、部落、派系也不应完全重合。一个同姓成员可以反对家主；两个不同营地的熟人可以继续交换；某个派系可以包含不同家族的人。

## 7. 失去领导权的完整体验

玩家坚持一次高风险报复，但营地依赖邻营的药材。有人公开提出异议，有人减少对出征的支持，也有人提出替代方案。

若分歧持续，成员可能依照当前组织的共同约定，撤回玩家对公共仓库或集体事务的授权，支持另一位协调者。也可能出现形式上的首领仍在位、实际已经无人愿意同行的状态。

玩家应该看得见变化过程：哪些要求无人响应，谁提出了什么意见，哪些已知承诺没有兑现。不能一条隐藏好感度跌破阈值就弹出“你被罢免”。

失位以后：

- 玩家保留角色、个人经历、私人财物与仍然存在的人际关系；职位授权可能撤销。
- 集体仓库不再是玩家随时取用的背包；个人物品也不能因失位凭空消失。
- 曾经的伙伴可以仍然感激玩家，同时支持新首领。
- 玩家可以接受新分工、与其他营地交易、离开、继续说服成员或组织新的合作。
- 新首领不是专门用来羞辱玩家的角色，也可以作出合理安排。

若之后发生驱逐、没收或攻击，必须作为新的行动，具有执行者、条件和后果，不能暗含在“失去职位”里。角色死亡的处理沿用原有生存模式，本扩展不擅自加入复活或继承控制。

## 8. 玩家可以怎样重新变得重要

帮助一个伤员，不一定换来职位，却可能换来下次有人愿意同行。履行一笔很难完成的交易，可能让陌生营地愿意接受玩家担保。长期保护某个团体，可能让其姓名或旗号逐渐被当地人认识。

也允许玩家不再追求领导权。作为可信赖的运输者、熟悉道路的向导或普通营地成员继续生活，是完整玩法，不是失败后的惩罚模式。

重新获得影响力需要新的经历。不能靠反复赠送廉价物品、不断重复同一段传闻或读档刷一句话，立即抹掉全部历史。

## 9. 玩家怎样理解世界，而不是读后台数据库

主要信息来自现场、交付记录、路上痕迹、公开回应和人物转述。界面可以显示“你听某人说”“你亲眼看到”“尚未证实”，但不能把隐藏动机包装成事实。

玩家可查看自己知道的承诺、货物、路线、职位权限及近期原因。不默认展示所有人的关系分数、全部派系图和私有库存。

调试工具可以显示更完整的状态以便开发者定位错误，但必须与正常游玩界面分离。

## 10. 反向验收

| 看起来发生了什么 | 为什么不达标 |
|---|---|
| 部落贸易了，但没有货物、运输者或交付变化 | 只有叙述，没有世界后果 |
| 一个成员犯错，全体成员瞬间攻击玩家 | 个体、组织责任和信息传播被跳过 |
| 首领下令，所有人永远立即执行 | 集体仍是一群工蜂 |
| 为了展示自主性，每次命令都随机有人拒绝 | 只有噪声，缺乏可理解的原因 |
| 没人愿意合作，玩家只能等待 | 自主性变成不可玩的管理阻力 |
| 一次失位让角色和全部私人财物重置 | 职位变化破坏了人生连续性 |
| 每局都固定发生失踪、误会、政变 | 把演示例子做成了隐藏主线 |
| 只有战争可以推动进展 | 和平、修复和日常生活被削弱 |

## 11. 体验验证问题

试玩时让玩家回述：我遇见了谁？谁帮助或反对过我？一件事怎样改变了下次合作？我失去的是一个职位还是整场游戏？我能否在不打开全知图的情况下理解局势？

验收同时观察和平发展与冲突发展。最终希望玩家说：

> “他们曾经愿意跟着我，后来有了自己的选择。我改变过这个地方，它也改变了我。现在我还可以决定接下来怎么生活。”
