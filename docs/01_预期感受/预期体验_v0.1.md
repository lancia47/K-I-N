# K-I-N｜预期体验 v0.1

> 这份文档只回答一个问题：**如果 K-I-N 做对了，玩家实际会有什么感觉？**

## 1. 世界不是等玩家触发才开始存在
玩家离开某个地方后，那里的人仍然有需求、关系、资源和后果。回来时应该感觉：**这里在我不在的时候发生过事情。**

## 2. NPC 是人，不是工蜂
玩家可以领导、请求、威慑、交换、承诺，但不天然拥有其他人的最高控制权。不同 NPC 会因为义务、恐惧、利益、家庭、债务和信任做出不同反应。

## 3. 生存行为会自然制造关系
狩猎、饥饿、伤病、救援、分配不是独立系统，而是关系发生的土壤：谁警告危险、谁搬运伤员、谁分肉、谁抛弃同伴，都会进入后续历史。

## 4. 玩家会记住具体的人
目标不是“人口 +1”或“好感度 +15”，而是：**这是上次狼袭时把我背回营地的人。**

## 5. 姓氏应该有重量
一个最初无意义的姓氏，应当因为十几个小时真实经历，逐渐变成别人会记住、畏惧、信任或怀疑的东西。

## 6. 微观关系和宏观势力是同一个世界
一次个人救援 → 形成个人声誉 → 部分附着到家族 → 家族获得更多追随者 → 组织影响扩大 → 陌生 NPC 因听过该组织而改变第一次互动。

## 7. 不可预测，但事后可以理解
目标不是随机混乱，而是：**我完全没想到事情会变成这样，但回头看，它确实是一步一步变成这样的。**

## 8. 每一局不是剧情不同，而是历史不同
不同存档最终应产生不同朋友与仇敌、家族、营地分裂、资源控制、组织声誉、领导关系和空间分布。

## 9. 攻略逐渐变成人的判断
玩家学习的不只是固定配方，而是判断利益、信任、身份、风险和信息真假。

## 10. 玩家不是世界的中心
玩家可以变得重要，但重要性必须被历史赚出来。失败、被遗忘、被背叛都是真实可能。

## 反向验收
- NPC 都像等命令的工蜂 → 失败
- 关系只是单一好感度 → 失败
- 所有人自动知道玩家做过什么 → 失败
- 家族只是一行 UI 标签 → 失败
- 组织按一下按钮就真实存在 → 失败
- 台词很多但资源和后果没变化 → 失败

## 一句话体验目标
> **玩家不是在完成一个写好的故事，而是在一个会记住他的世界里生活；多年以后，他看到的不只是自己的角色成长，而是自己参与形成的一段历史。**
