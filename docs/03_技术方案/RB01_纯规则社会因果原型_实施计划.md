# Pure-Rule Social Causality Prototype Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first runnable KIN prototype that proves a world event can produce different perceptions, memories, beliefs, relationship changes, and a different second decision — using deterministic rules only.

**Architecture:** A small pure-Python simulation package with no engine dependency and no online model calls. World truth, perception, memory, belief, relationship state, and decision rules are separate modules. The prototype runs entirely in tests and a CLI trace so causal changes can be inspected before any Godot integration.

**Tech Stack:** Python 3.11+, standard library, pytest.

**Spec:** `docs/02_设计文档/社会因果系统_v0.1.md` and `docs/03_技术方案/当前开发路线_v0.1.md`

## Global Constraints

- No Jev / LLM / online model calls in this prototype.
- World facts and agent beliefs remain separate.
- Agents cannot read hidden inventory or global truth.
- Relationship changes must have a traceable source event.
- The same evidence cannot be counted repeatedly as independent evidence.
- No Godot integration in this plan.
- No trade, faction, war, or leadership implementation in this plan.
- New runtime parameters are deterministic and versioned.
- Do not claim the reviewer-defined “Test A–H” exists; the repo has no canonical A–H definitions. This plan introduces `RB-01` explicitly.

## Review Focus

- Hidden data leakage: observers must never receive A's private inventory.
- Duplicate evidence: replaying the same perceived event must not double-apply relationship changes.
- Determinism: same initial state and event sequence must produce the same final state.
- Save/restore boundary: serialized rule state must round-trip without changing the next decision.
- No accidental narrative logic: decisions must come from explicit state, not hard-coded story outputs.
