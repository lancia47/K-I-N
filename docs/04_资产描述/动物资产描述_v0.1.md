# K-I-N｜动物资产描述 v0.1

> 这里只描述资产需求、来源、许可、动画覆盖和 Godot 导入状态，不混入玩法设计。

**当前状态：首批需求已定义；具体资产包、许可、SHA256 与导入结果待逐项审计。**

## 首批目标
| 物种 | 生态角色 | 最低表现需求 |
|---|---|---|
| 鹿 | 温顺大型猎物 | 警觉、逃跑、追踪 |
| 狼 | 群体捕食者 | 威胁、追击、攻击、撤退 |
| 狐 | 小型机会型动物 | 回避、游走 |
| 野猪 | 强壮杂食动物 | 警戒、冲撞/反击 |
| 兔 | 小型猎物 | 快速逃逸 |
| 鱼 | 水域资源 | 捕鱼、食物来源 |
| 鸟 | 环境活性 | 声音/视觉生态线索 |
| 熊/同等级危险兽 | 大型威胁 | 高风险遭遇、撤退/救援压力 |

## 许可与来源
优先 CC0。每个候选必须记录：来源 URL、包名、作者、许可、许可证据、版本、下载时间、SHA256。

## 最低动画覆盖
- idle
- walk / locomotion
- run（适用时）
- attack 或 escape
- hit / hurt
- death

## Godot 导入检查
- 原始格式与实际导入格式
- 骨骼与动画名
- 材质、法线、朝向
- 比例与碰撞体
- 镜头距离可读性
- headless / GUI 导入一致性

## 玩法线索资产
动物不仅要“好看”，还要能提供声音、脚印/路线、血迹、尸体、警戒姿态、逃跑方向、活动区域等可观察线索。

## 当前不做
幼体、性别差异、繁殖动画、疾病表现、大规模季节换毛、遗传变体、过多同生态位物种。
