# K-I-N｜部落求生

K-I-N 的开发目标，是让玩家和一群有自己需求、会记住过去的 NPC 一起生活：采集、制作工具、狩猎、照料伤员、分配食物，逐渐接触其他营地，参与贸易、冲突和部落内部的共同决定。

玩家可以成为首领，也可以做运输者、猎人、向导或普通成员。别人不必永远服从玩家；失去领导权以后，只要角色仍存活并能行动，仍然可以继续生活、交易、离开或重新争取支持。

**这里目前整理的是设计文档与开发路线。文档写好不代表玩法已经实现；实际代码、测试和试玩进度以证据为准。**

## 我们具体想让玩家经历什么？

先从一件小事做起：大家一起狩猎，有人受伤，玩家选择救援或返回营地。之后如何分配猎物，会让不同的人记住不同的事情，并影响下一次谁愿意同行、谁向谁求助。

再把这种关系延伸到部落之间：河边营地拿食物与山边营地交换药材。运输迟到，有人主张搜救，有人怀疑对方反悔。玩家带回的证据、救回的人和履行的承诺，会影响交易是否继续，也会改变营地里谁的意见更受支持。

玩家甚至可能因为坚持一场大家不愿参加的报复而失去领导权。但这不是必须发生的剧情：双方也可以和平解决分歧，营地继续信任玩家。系统需要允许这些不同结果，由实际行动和后果决定。

## 现在先做什么，后面再做什么？

| 顺序 | 要做的事情 | 完成的判断 |
|---|---|---|
| 当前底座 | 采集、工具、火源、食物、伤病与营地库存 | 能正常生存，状态正确，保存后可恢复 |
| 当前生态 | 多种动物、追踪、狩猎、危险与救援 | 动物反应不同，资源和伤势真实变化 |
| 当前社会层 | 记住救援、抛弃、分配与实际履约 | 不同经历改变下一次合作 |
| 后续两营扩展 | 交易、运货、交付、延误与修复 | 货物真的送达，消息与关系有来源 |
| 后续集体生活 | 协商、派系、领导更替与有限冲突 | 成员能合作和反对，玩家失位后仍可玩 |
| 更后面的三营扩展 | 第三方担保、替代伙伴、联盟与中立 | 世界不依赖玩家和唯一一条交易路线 |

现有阶段 0–7 的顺序不变。生存和生态没有通过验收，不抢跑社会关系；个人社会因果和联合试玩没有通过，不直接扩展多部落。第一版继续用规则驱动 NPC，不接在线模型，不用增加模型调用代替世界规则。

## 什么情况说明做偏了？

如果交易只是仓库数字瞬移、战争只靠敌对值触发、派系只是颜色标签、NPC 为了展示自主性随机拒绝，或者玩家失位就清空人物历史，都没有达到目标。

我们要验证的是：**一件实际发生的事，被不同的人以不同方式知道和记住，改变之后的合作；这些合作逐渐影响整个部落，而玩家始终能够在其中继续行动。**
