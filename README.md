# K-I-N

> **一个以“关系会改变行为，历史会改变世界”为核心的部落生存与社会模拟项目。**

K-I-N 从一小群探险者开始。

玩家需要面对最基本的生存问题：采集、工具、火源、狩猎、伤病、食物和营地；但这些系统不是终点。真正的目标，是让这些日常行为逐渐产生**记忆、信任、债务、怨恨、身份、派系、贸易、冲突和组织结构**。

玩家可以成为首领，也可以只是猎人、运输者、向导、担保人或普通成员。NPC 不会永远服从玩家；玩家也可能因为自己的选择失去领导权，但只要角色仍然活着，就可以继续在同一个世界里生活。

---

# 1. 这个游戏最想实现什么？

K-I-N 不把 NPC 当成等待命令的工蜂。

我们希望 NPC：

- 有自己的需求和目标；
- 只知道自己真正接触到的信息；
- 会记住重要经历；
- 会因为过去改变之后的选择；
- 会形成合作、偏见、债务、恐惧和信任；
- 会支持玩家，也会反对玩家；
- 会组成家族、派系和部落；
- 会在玩家不介入时继续做自己的事情。

一个最小例子：

共同狩猎 → 有人受伤 → 有人警告 / 救援 / 抛弃 → 猎物重新分配 → NPC 形成不同记忆 → 关系变化 → 下一次狩猎的合作对象和分工改变。

再把同样逻辑扩大到部落之间：

两个营地交换资源 → 有人运输 → 一次交付迟到 → 有人主张搜救，有人怀疑违约 → 玩家带回证据或救回运输者 → 交易与内部支持发生变化 → 反复合作形成派系 → 玩家可能继续领导，也可能失去领导权。

这些结果不是预写剧情。系统只提供真实的资源、行动、信息、记忆和后果，让历史自己长出来。

# 2. 核心体验

## 世界不是围着我转的
玩家离开以后，其他人仍然会采集、交易、争执、救援、合作和改变关系。玩家回来时，希望产生：**“这里在我不在的时候真的发生过事情。”**

## 我记住的是人，不是数值
目标不是“NPC 好感度 +15”，而是：**“这是上次狼袭时把我背回营地的人。”**

同一个 NPC 可以同时不喜欢玩家、欠玩家救命之恩、信任玩家能力、害怕玩家所属的家族，并反对玩家当前的决定。

## 姓氏和组织会慢慢获得重量
玩家最初取的姓氏可能没有任何意义。但随着真实历史积累，它可能逐渐意味着：会保护自己人、从不赖账、危险、值得合作，或者曾经背叛盟友。

理想体验是某一天，一个从未见过玩家的 NPC 说：**“我不认识你，但我听说过这个姓氏。”**

## 玩家可以失去权力，但不会因此失去人生
玩家可以建立营地、成为首领，也可能因为长期分歧失去公共仓库和集体事务的授权。但这不自动 Game Over。玩家仍可以工作、狩猎、交易、帮助旧伙伴、离开部落、加入其他团体或重新争取支持。

# 3. 当前开发顺序

| 顺序 | 开发内容 | 主要验证 |
|---|---|---|
| 1 | **生存底座** | 采集、工具、火源、食物、伤病、库存真实运行 |
| 2 | **多物种生态** | 不同动物拥有不同移动、逃跑、攻击和危险反应 |
| 3 | **生态事件** | 狩猎、警告、救援、搬运、分配形成真实事件 |
| 4 | **个人社会因果** | 不同 NPC 对同一事件形成不同 Memory / Belief / Relationship |
| 5 | **两营贸易** | 货物真实运输、交付、延误、搜救和修复 |
| 6 | **集体决定与派系** | NPC 能支持、反对、协商；反复合作形成团体 |
| 7 | **领导更替与有限冲突** | 玩家可以失位后继续生活；冲突有目标也有停止条件 |
| 8 | **三营网络** | 第三方担保、替代交易伙伴、联盟、中立和更复杂关系 |

> **WorldCore 先成立，社会因果后接入。** 如果生存、资源、伤势、货物和位置都不能真实结算，那么“记忆”和“关系”只会变成文本表演。

# 6. 项目原则

### NPC 不是工蜂
玩家的命令只是一个社会输入，不是对所有 NPC 的绝对控制。

### 世界事实和人物认知分开
World State 与 Belief State 不相同。NPC 只能依据自己知道、听说和相信的内容行动。

### 模型不能直接修改世界
AI 可以决定“我想做什么”；WorldCore 决定“这件事是否能做，以及真实发生了什么”。

### 关系不是单一好感度
信任、恐惧、尊重、义务、怨恨、熟悉程度等可以同时存在。

### 组织不是颜色标签
家族、派系、部落和联盟必须通过实际成员、承诺、资源、行动和历史维持。

### 战争不是敌对值触发器
冲突需要具体争议、实际参与者、资源与行动、明确目标和停止条件。和平、赔偿、归还和重新合作与战争同样重要。

### 玩家不是世界中心
玩家可以改变世界，但世界不会保证玩家永远重要、永远正确或永远掌权。

### 故事来自历史，不由系统强迫发生
我们不规定“第 20 天必须战争、第 30 天必须政变”。我们要求的是：**当事情真的发生以后，能够追溯它为什么一步一步变成这样。**

# 当前最小证明

K-I-N 现在真正需要证明的，不是“大模型 NPC 能不能说得像真人”。

> **一个真实发生的事件，能否被不同的人以不同方式知道和记住；这些经历能否改变关系；这些关系能否改变下一次选择；大量这样的选择最终能否形成玩家没有预先写好的部落历史。**

如果这一点成立，再向更大的部落、贸易网络、战争、家族、派系与文明扩展。
