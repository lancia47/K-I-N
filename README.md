# K-I-N

K-I-N 是一个正在开发中的 **生存 + 生态 + NPC 社会关系模拟游戏原型**。

游戏从一小群探险者开始。玩家需要解决吃饭、工具、狩猎、伤病、营地和资源分配，同时和一群**会记住过去、会形成关系、不会永远服从玩家**的 NPC 一起生活。

我们目前最想做出来的不是“大地图”或“大量剧情”，而是下面这件事：

```text
一起狩猎
→ 有人受伤
→ 有人警告 / 救援 / 抛弃
→ 猎物和资源被重新分配
→ NPC 记住发生过什么
→ 信任、恐惧、债务、怨恨发生变化
→ 下一次狩猎、求助和分工出现不同选择
```

如果这条链能够真实运行，后面才继续扩展到：

```text
个人关系
→ 姓氏 / 家族
→ 营地 / 派系
→ 更大的社会结构
```

---

## 目前在做什么

当前开发顺序已经确定：

1. **先把生存底座做稳**
   - 采集
   - 工具
   - 火源
   - 捕鱼 / 狩猎
   - 烹饪
   - 伤病
   - 营地库存

2. **加入多种动物生态**
   - 鹿、狼、狐、野猪、兔、鱼、鸟、大型危险兽
   - 不同动物有不同移动、逃跑、攻击和危险反应

3. **把生态事件记录下来**
   - 谁看见了动物
   - 谁警告了别人
   - 谁救了伤员
   - 谁抛弃了成员
   - 谁拿走了猎物
   - 谁分出了食物

4. **再接入 NPC 记忆和关系**
   - Memory
   - Belief
   - Trust / Fear / Obligation / Resentment
   - 信息传播和误解

5. **最后验证关系是否真的会改变下一次行为**

> 当前原则：**生存和生态没有跑通之前，不抢跑社会关系系统。**

## 当前最小目标

不是先做完整开放世界。

先证明这一小段能成立：

> **NPC 经历一件真实发生的事情之后，会以不同方式记住它；这些记忆会形成不同关系；这些关系会在下一次事件中真实改变他们的选择。**

做到这一点之后，再向家族、派系、社会结构扩展。
